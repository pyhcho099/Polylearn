5Summarize the types of learning in AI.M13 marks

Priority: 🔴 HIGH — Asked in Part B of April 2026 and the model question paper.

Your materials use slightly different lists of learning types. To avoid confusion, learn the following distinctions.

A. Main machine-learning approaches

1Supervised Learning

The model learns from labelled data, where inputs are paired with the correct outputs. It is used for classification and regression.

Example: Predicting whether an email is spam.

2Unsupervised Learning

The model learns from unlabelled data and identifies patterns or groups without being given the correct output for each example.

Example: Grouping customers with similar behaviour.

3Reinforcement Learning

An agent learns by interacting with an environment and receiving rewards or penalties for its actions.

Example: An AI agent learning to play a game.

These three are the types listed in the model question paper.

B. What about Semi-supervised Learning?

Your Module 1 notes also discuss Semi-supervised Learning.

It uses a combination of labelled and unlabelled data. It is useful when obtaining labelled data is expensive or time-consuming.

1Explain conditional statements in Python.M27 marks

Asked in April 2026, Part C.

Answer

Conditional statements in Python are used to make decisions based on conditions. They allow a program to execute different blocks of code depending on whether a condition is true or false.

Python provides the following conditional statements.

1if statement

The if statement executes a block of code when the given condition is true.

Syntax

if condition:
    statements

Example

num = 5

if num > 0:
    print("The number is positive.")

Output

The number is positive.

2if-else statement

The if-else statement executes one block when the condition is true and another block when the condition is false.

Syntax

if condition:
    statements
else:
    statements

Example

num = 7

if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")

Output

Odd number

3if-elif-else statement

The if-elif-else statement is used when multiple conditions must be checked. Python executes the block belonging to the first condition that evaluates to true.

Syntax

if condition1:
    statements
elif condition2:
    statements
else:
    statements

Example

marks = 85

if marks >= 90:
    print("Grade S")
elif marks >= 80:
    print("Grade A")
elif marks >= 70:
    print("Grade B")
else:
    print("Grade C")

Output

Grade A

4Nested if statement

A nested if statement is an if statement placed inside another if statement. It is useful when a second condition should be checked only after the first condition is satisfied.

Example

num = 10

if num > 0:
    if num % 2 == 0:
        print("Positive even number")

Output

  • Positive even number
  • Conclusion

Conditional statements control the flow of a Python program and allow it to make decisions based on given conditions.

Exam strategy: Learn all four types, their syntax, and at least one example. The April 2026 question asks for a 7-mark explanation, so don't write only the definitions.

2Write a Python program to create three dictionaries, concatenate them into a fourth dictionary, and check whether a dictionary is empty.M27 marks

Asked in April 2026, Part C.

Answer

A dictionary in Python stores data as key-value pairs. Dictionaries are created using curly brackets {}.

Dictionaries can be combined using the update() method.

Program

# Creating three dictionaries
d1 = {"a": 1, "b": 2}
d2 = {"c": 3, "d": 4}
d3 = {"e": 5, "f": 6}

# Creating a fourth dictionary
d4 = {}

# Concatenating the dictionaries
d4.update(d1)
d4.update(d2)
d4.update(d3)

# Displaying the fourth dictionary
print("Combined dictionary:", d4)

# Checking whether the dictionary is empty
if not d4:
    print("Dictionary is empty")
else:
    print("Dictionary is not empty")

Output

Combined dictionary: {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6}
Dictionary is not empty

Explanation

1Three dictionaries, d1, d2, and d3, are created with different key-value pairs.
2An empty dictionary, d4, is created.
3The update() method copies the contents of each dictionary into d4.
4The combined dictionary is displayed using print().
5The condition if not d4 checks whether d4 is empty.
6If it is empty, the program prints "Dictionary is empty".
7Otherwise, it prints "Dictionary is not empty".

Remember: If two dictionaries contain the same key, the value from the dictionary updated later replaces the earlier value for that key.

7Explain the while loop in Python with a suitable example.M23 marks

Asked in April 2026, Part B.

Answer

A while loop repeatedly executes a block of statements as long as the given condition remains true. It is useful when the number of iterations is not known in advance.

Syntax

while condition:
    statements

Example

i = 1

while i < 6:
    print(i)
    i += 1

Output

1
2
3
4
5

Explanation

1The variable i is initialised to 1.
2The condition i < 6 is checked before every iteration.
3The value of i is printed while the condition is true.
4i += 1 increases the value of i by one.
5The loop stops when i becomes 6.

Important: If you forget to update the variable or otherwise make the condition false, a while loop may run indefinitely.

8Write a Python program using a for loop to calculate the factorial of a given number.M23 marks

Asked in April 2026, Part B.

Answer

The factorial of a non-negative integer n is the product of all positive integers from 1 to n. The factorial of 0 is 1.

For example

5! = 5 × 4 × 3 × 2 × 1 = 120

Program

  • n = int(input("Enter a number: "))
  • fact = 1
for i in range(2, n + 1):
    fact = fact * i

print("Factorial =", fact)

Output

Enter a number: 5
Factorial = 120

Explanation

1The program accepts a number from the user.
2fact is initialised to 1.
3The for loop iterates from 2 to n.
4Each value of i is multiplied by fact.
5The final factorial is displayed.

Note: This program assumes the input is a non-negative integer. If the input is 0, the loop does not run and the result remains 1.

10Explain the range() function with an example.M2

Answer

The range() function generates a sequence of integers. It is commonly used with a for loop to repeat statements a specified number of times.

Syntax

range(start, stop, step)

start: The starting value; defaults to 0.

stop: The ending boundary, which is excluded.

step: The increment or decrement between values; defaults to 1.

Example

for i in range(2, 10, 3):
    print(i)

Output

2
5
8

The sequence starts at 2, increases by 3, and stops before reaching 10.

1Define a classifier and list the metrics used to measure its performance.M37 marks

Asked in April 2026, Part C.

Answer

A classifier is a supervised machine-learning model that learns from labelled training data and predicts the class or category of new data.

For example, a classifier can identify whether an email is spam or not spam.

The performance of a classifier can be evaluated using the following metrics.

1Accuracy

Accuracy measures the proportion of predictions that the model classifies correctly out of all predictions.

\[
\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}
\]

2Precision

Precision measures how many of the instances predicted as positive are actually positive.

\[
\text{Precision}=\frac{TP}{TP+FP}
\]

3Recall

Recall measures how many of the actual positive instances are correctly identified by the classifier.

\[
\text{Recall}=\frac{TP}{TP+FN}
\]

4F1-score

The F1-score combines precision and recall using their harmonic mean. It is useful when both precision and recall matter.

\[
F1=2\times\frac{\text{Precision}\times\text{Recall}}{\text{Precision}+\text{Recall}}
\]

5Confusion Matrix

A confusion matrix summarises the model's predictions by comparing predicted classes with actual classes. For binary classification, it contains four outcomes:

TP — True Positive: Positive cases correctly predicted as positive.

TN — True Negative: Negative cases correctly predicted as negative.

FP — False Positive: Negative cases incorrectly predicted as positive.

FN — False Negative: Positive cases incorrectly predicted as negative.

Conclusion

Accuracy, precision, recall, F1-score, and the confusion matrix help evaluate a classifier and understand its strengths and weaknesses.

2Summarize the K-Nearest Neighbour (KNN) algorithm in Machine Learning.M37 marks

Asked in April 2026, Part C.

Answer

K-Nearest Neighbour (KNN) is a simple supervised machine-learning algorithm that classifies new data based on its similarity to existing data.

It is commonly used for classification, but it can also be used for regression.

Features of KNN

1Supervised learning: KNN uses labelled training data to predict the class of new data.
2Similarity-based classification: It assigns a new data point to a category based on the nearest training examples.
3Non-parametric algorithm: KNN does not assume a particular underlying probability distribution for the data.
4Lazy learner: It stores the training data rather than building an explicit generalised model during a separate training phase. The main calculations happen when a prediction is required.
5Uses distance calculations: KNN commonly uses Euclidean distance to determine which data points are nearest.
6Choice of K matters: The value of K determines how many neighbours are considered. A very small K may be sensitive to noise, while a larger K can produce different classification results.
7Classification and regression: KNN can predict a class through neighbour voting or estimate a numerical value using neighbouring observations.

Working steps of KNN

Step 1: Choose K.
Select the number of nearest neighbours to consider.

Step 2: Calculate distances.
Calculate the distance between the new data point and the training data points.

Step 3: Find the nearest neighbours.
Select the K data points with the smallest distances.

Step 4: Count the classes.
For classification, count how many of the selected neighbours belong to each class.

Step 5: Assign the class.
Assign the new data point to the class with the highest number of neighbours.

Step 6: Produce the prediction.
Return the predicted class for the new data point.

Example

Suppose a model has already learned from labelled images of cats and dogs. When it receives a new animal image, KNN compares its features with the stored examples. If most of its nearest neighbours belong to the cat class, it classifies the new image as a cat.

Advantages

Simple to understand and implement.

Can be useful with noisy training data.

Can work effectively with sufficiently representative training data.

Disadvantages

Choosing an appropriate K can be difficult.

Prediction can be computationally expensive because distances must be calculated against stored training examples.

Conclusion: KNN predicts a new data point using the classes or values of its nearest neighbours.

3Summarize the features of K-Means in Machine Learning.M37 marks

Asked in April 2026, Part C.

Answer

K-Means is an unsupervised machine-learning algorithm used to divide an unlabelled dataset into a specified number of groups called clusters.

The value K represents the number of clusters to be created.

Features of K-Means

1Unsupervised learning

K-Means works with unlabelled data. It does not require the correct class label for every data point.

2Clustering

It groups data points with similar characteristics into the same cluster.

3Predetermined value of K

The user chooses the number of clusters before running the algorithm. For example, if K = 3, the algorithm aims to create three clusters.

4Centroid-based algorithm

Each cluster is represented by a centroid, which acts as its centre.

5Iterative process

The algorithm repeatedly assigns data points to clusters and recalculates their centroids.

6Distance-based assignment

Each data point is assigned to the nearest centroid according to the chosen distance measure, commonly Euclidean distance.

7Minimises within-cluster distances

The algorithm aims to reduce the distances between data points and their corresponding cluster centroids.

Working steps of K-Means

1Choose the number of clusters, K.
2Select K initial centroids.
3Calculate the distance from each data point to the centroids.
4Assign each data point to its nearest centroid, forming clusters.
5Recalculate the centroid of each cluster.
6Reassign the data points using the updated centroids.
7Repeat the process until the assignments or centroids stop changing significantly.

Example

A shop has information about its customers' purchases but does not have predefined customer groups. K-Means can group customers with similar purchasing behaviour into clusters. The shop can then study each cluster to understand different customer groups.

Conclusion

K-Means is a centroid-based, iterative, unsupervised algorithm that groups unlabelled data into K clusters according to similarity.

9Explain data preprocessing and its techniques.M37 marks

Answer

Data preprocessing is the process of preparing raw data so that it is suitable for machine-learning algorithms.

Raw data may contain values on different scales or formats. Preprocessing transforms the data into a form that is more appropriate for analysis and model training.

Your Module 3 notes cover the following techniques.

1Binarization

Binarization transforms numerical features into binary values, generally 0 and 1, using a threshold.

Example: Converting numerical pixel values into black-and-white values.

2Mean Removal

Mean removal subtracts the mean of a feature from its values so that the feature is centred around zero.

It can help remove a feature's offset and make data more suitable for certain algorithms.

Basic formula

\[
x_{\text{new}}=x-\bar{x}
\]

Here, x is an original value and \bar{x} is the feature's mean.

3Scaling

Scaling changes the numerical range of features so that they are represented on a more comparable scale.

For example, Min-Max scaling transforms values to a range such as 0 to 1.

Min-Max scaling formula

\[
x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}}
\]

Here

x is the original value.

x_{\min} is the minimum value.

x_{\max} is the maximum value.

4Normalization

Normalization transforms data according to a specified rule or scale. The precise operation depends on the normalization method used.

It can help prepare data for algorithms that are sensitive to feature magnitude.

Conclusion

Binarization, mean removal, scaling, and normalization help prepare numerical data for machine-learning tasks.

4What are uninformed search algorithms?M43 marks

Definition: Uninformed search is a search technique that explores the search space without using additional domain knowledge about how close a state is to the goal. It is also called blind search.

It uses information such as the initial state, available actions, and goal test.

Types of uninformed search

1Depth-First Search (DFS): Explores one path as deeply as possible before backtracking.
2Breadth-First Search (BFS): Explores all nodes at one level before moving to the next level.
3Uniform-Cost Search (UCS): Expands the node with the lowest cumulative path cost.

5Explain Depth-First Search (DFS).M43 marks

Definition: Depth-First Search is a search algorithm that explores a tree or graph by following one path to its greatest depth before backtracking and exploring another path.

Working

1Start from the root or initial node.
2Visit an unvisited neighbouring node.
3Continue exploring deeper nodes along that path.
4When no further unvisited node is available, backtrack.
5Continue until the goal is found or the search is exhausted.

Data structure used

Stack (LIFO — Last In, First Out).

DFS can also be implemented recursively.

Example

Consider this tree

A
       / \
      B   C
     / \
    D   E

One possible DFS traversal is

A → B → D → E → C

The exact order depends on which child is explored first.

6Explain Breadth-First Search (BFS).M43 marks

Definition: Breadth-First Search is a search algorithm that explores all nodes at the current level before moving to nodes at the next level.

Working

1Begin at the root node.
2Visit the current node.
3Add its unvisited neighbouring nodes to a queue.
4Remove the node at the front of the queue.
5Repeat until the goal is found or no nodes remain.

Data structure used

Queue (FIFO — First In, First Out).

Example

Using the same tree

A
       / \
      B   C
     / \
    D   E

BFS traversal

  • A → B → C → D → E

7Explain Uniform-Cost Search (UCS).M43 marks

Definition: Uniform-Cost Search is a search algorithm used on a weighted tree or graph. It expands the node with the lowest cumulative path cost.

Working

1Begin at the start node with a path cost of zero.
2Place available nodes in a priority queue.
3Select the node with the lowest cumulative cost.
4Expand that node and calculate the costs of its successors.
5Continue until the goal is reached under the algorithm's appropriate stopping conditions.

Data structure used

Priority Queue.

Main feature

UCS is useful when different edges have different costs and the objective is to find the least-cost path.

8What is informed search?M43 marks

Definition: Informed search is a search technique that uses additional problem knowledge to guide the search towards the goal. It is also called heuristic search.

Features

1It uses information about the problem to guide the search.
2It uses a heuristic function to estimate how close a state is to the goal.
3It can explore the search space more efficiently than an uninformed method in suitable problems.
4Examples include Greedy Best-First Search and A* Search.

What is a heuristic?

A heuristic is a function that estimates how close a particular state is to the goal state.

Examples include Manhattan distance and Euclidean distance.

9Explain Greedy Best-First Search.M43 marks

Definition: Greedy Best-First Search selects the node that appears most promising according to its heuristic estimate.

Working

1Start with the initial node.
2Estimate how close the available nodes are to the goal using a heuristic.
3Select the node that appears closest to the goal.
4Expand that node and evaluate its successors.
5Continue until the goal is found or no suitable nodes remain.

Main feature

It tries to reach the goal quickly by choosing the most promising node at each step.

Limitation: It does not always find the least-cost path because it does not necessarily account for the full cost already incurred.

10Explain A* Search.M43 marks

Definition: A* is an informed search algorithm that combines the cost of reaching a node with an estimate of the remaining cost to reach the goal.

It uses the evaluation function

\[
\boxed{f(n)=g(n)+h(n)}
\]

Where

  • f(n) = estimated total cost through node n
  • g(n) = cost from the start node to node n
  • h(n) = estimated cost from node n to the goal

Working

1Start from the initial node.
2Calculate the evaluation value f(n) for the available nodes.
3Select a node with the lowest evaluation value.
4Expand it and calculate the evaluation values of its successors.
5Continue until the goal is reached.

Main feature

A* combines the actual path cost and the estimated remaining cost to guide the search.

With a suitable admissible heuristic and the appropriate graph-search implementation, A* can find an optimal path.

Important distinction

Your notes describe Greedy Search using h(n) as the estimate of the remaining cost and A* using g(n)+h(n).

Learn the A formula exactly:* f(n)=g(n)+h(n).

14Explain the Minimax algorithm.M4🖊️ Diagram7 marks

HIGH PRIORITY — Learn this answer properly.

1Definition

The Minimax algorithm is a recursive search algorithm used in artificial intelligence and game theory. It determines an optimal move by assuming that the opponent also chooses the best possible moves.

It is commonly used in two-player games such as Tic-Tac-Toe.

2Players

Minimax uses two players

MAX: Attempts to obtain the maximum possible score.

MIN: Attempts to obtain the minimum possible score.

Each player tries to select a move that benefits them while limiting the opponent's advantage.

3Game tree

A game tree represents the possible moves and resulting states of a game.

The root represents the current game state.

Each branch represents a possible move.

The child nodes represent the states resulting from those moves.

The leaf nodes represent terminal states or states evaluated at the search-depth limit.

4Terminal-state evaluation

When a terminal state is reached, the algorithm assigns a numerical value to it.

  • For Tic-Tac-Toe, your notes use the following utility values:
  • +1: Win
  • −1: Loss
  • 0: Draw

These values are from the perspective of the player for whom the utility is defined.

5Working of Minimax

1Start from the current game state.
2Generate the possible moves.
3Explore the resulting game tree using depth-first search.
4Continue until terminal nodes or the chosen search-depth limit is reached.
5Assign evaluation values to the resulting states.
6Move backwards through the tree.
7At a MAX node, select the maximum child value.
8At a MIN node, select the minimum child value.
9Choose the move that gives the best value for the current player, assuming the opponent also plays optimally.

6Decision rule

For MAX

\[
V(s)=\max_{a}V(\operatorname{Result}(s,a))
\]

For MIN

\[
V(s)=\min_{a}V(\operatorname{Result}(s,a))
\]

Here, V(s) represents the value of state s.

7Advantages

1It helps AI choose strategic moves.
2It considers the opponent's possible responses.
3It can determine an optimal move when the relevant game tree is searched completely and the evaluation is correct.

8Limitation

Minimax can examine a large number of game states. For complex games, this can require considerable processing time and memory.

Conclusion: Minimax enables a game-playing AI to choose moves by considering both its own objectives and the opponent's possible responses.

15Explain Alpha-Beta Pruning.M43–5 marks

Definition

Alpha-Beta Pruning is an optimization technique used with Minimax to avoid exploring game-tree branches that cannot affect the final decision.

Why is it needed?

Minimax may examine branches that are irrelevant to the final decision. Alpha-Beta Pruning avoids unnecessary exploration and can reduce the amount of work required.

Important terms

Alpha (α): The best value MAX can guarantee so far; it acts as a lower bound.

Beta (β): The best value MIN can guarantee so far; it acts as an upper bound.

Working

1Begin searching the game tree using Minimax.
2Maintain the current alpha and beta bounds.
3Update alpha when MAX finds a better value.
4Update beta when MIN finds a better value.
5When the bounds show that a branch cannot improve the final decision, stop exploring that branch.
6Continue evaluating the remaining relevant branches.

The common pruning condition is

\[
\boxed{\alpha \geq \beta}
\]

Advantages

1Avoids unnecessary exploration of branches.
2Can make Minimax search more efficient.
3Can allow deeper searches with the same computational resources.
4Produces the same decision as ordinary Minimax when applied correctly.

Remember: Alpha-Beta Pruning does not change the Minimax result; it reduces unnecessary search.
