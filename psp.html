🔸 3 MARKS QUESTIONS (Short answers / small programs)
#QuestionAnswer / Explanation
1 Write the output and explain:
int a[5] = {5,1,15,20,25};
int i, j, m; i = ++a[1]; j = a[1]++; m = a[i++];
printf("%d, %d, %d", i, j, m); 		Output: 3, 2, 15
Explanation:
- a[1] is 1. ++a[1] → pre‑increment → a[1]=2, i=2.
- j = a[1]++ → post‑increment → j=2, then a[1]=3.
- i++ uses i=2 → m = a[2] = 15, then i becomes 3.
- Print i=3, j=2, m=15.
2 How to find whether two strings are equal using built‑in function? Give example. Use strcmp(str1, str2). Returns 0 if equal.
Example: if(strcmp(s1, s2) == 0) printf("Equal");
3 What is Call by Reference? Give an example. In Call by Reference, address of actual arguments is passed, so changes affect original variables.
Example: 
void swap(int *a, int *b) { int t=*a; *a=*b; *b=t; }
4 List advantages of dynamic memory allocation. 1. Memory allocated at runtime.
2. Efficient memory usage.
3. Can create variable‑sized data structures (e.g., linked lists).
4. Memory can be freed when not needed.
5 How to access array elements using pointers? int arr[5], *p = arr; Then *(p+i) accesses arr[i].
6 Differentiate between formal and actual parameters. Actual parameters: arguments passed in function call.
Formal parameters: variables declared in function definition that receive values.

9 Explain the continue statement with a short note. continue skips the remaining statements in the current loop iteration and jumps to the next iteration.
Example: for(i=0;i<10;i++) { if(i==5) continue; printf("%d",i); } // prints 0‑4,6‑9

1 Write a C program to find sum of first n numbers using recursion. 
#include <stdio.h>
int sum(int n) {
    if(n == 0) return 0;
    return n + sum(n-1);
}
int main() {
    int n;
    printf("Enter n: ");
    scanf("%d", &n);
    printf("Sum = %d", sum(n));
    return 0;
}
2 Explain parameter passing method in a given program (area of rectangle). The program uses Call by Value. The values of a and b from main() are copied into the formal parameters l and b of area(). Changes inside area() do not affect original variables. The result is returned.
3 Write a program to convert given seconds into hours, minutes, seconds. 
#include <stdio.h>
int main() {
    int total, h, m, s;
    printf("Enter seconds: ");
    scanf("%d", &total);
    h = total / 3600;
    m = (total % 3600) / 60;
    s = total % 60;
    printf("Hours = %d, Minutes = %d, Seconds = %d", h, m, s);
    return 0;
}
4 Explain different looping statements with examples. 1. `for` loop: for(init; condition; inc) { } – known iterations.
Example: for(i=0;i<5;i++) printf("%d",i);

2. `while` loop: entry‑controlled.
Example: while(i<5) { printf("%d",i); i++; }

3. `do‑while` loop: exit‑controlled, executes at least once.
Example: do { scanf("%d",&n); } while(n>0);
5 Write a program to calculate electricity bill based on given slab rates. 
#include <stdio.h>
int main() {
    int units;
    float bill;
    scanf("%d", &units);
    if(units <= 150)
        bill = units * 3;
    else if(units <= 350)
        bill = 450 + (units-150)*3.75;
    else if(units <= 450)
        bill = 1200 + (units-350)*4;
    else
        bill = 1600 + (units-450)*5;
    printf("Bill = Rs. %.2f", bill);
    return 0;
}
6 Write a program to sort an integer array in ascending order (bubble sort). 
#include <stdio.h>
int main() {
    int n, arr[100], i, j, temp;
    scanf("%d", &n);
    for(i=0;i<n;i++) scanf("%d", &arr[i]);
    for(i=0;i<n-1;i++)
        for(j=0;j<n-i-1;j++)
            if(arr[j] > arr[j+1]) {
                temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
    for(i=0;i<n;i++) printf("%d ", arr[i]);
    return 0;
}
7 Write a program to find the largest number in a given matrix. 
#include <stdio.h>
int main() {
    int r, c, mat[10][10], i, j, max;
    scanf("%d %d", &r, &c);
    for(i=0;i<r;i++)
        for(j=0;j<c;j++)
            scanf("%d", &mat[i][j]);
    max = mat[0][0];
    for(i=0;i<r;i++)
        for(j=0;j<c;j++)
            if(mat[i][j] > max) max = mat[i][j];
    printf("Largest = %d", max);
    return 0;
}
8 Describe the steps in compiling and executing a C program. 1. Editing: Writing source code (.c file).
2. Preprocessing: Handles #include, #define.
3. Compilation: Translates to assembly code.
4. Assembly: Converts to machine code (object file .obj/.o).
5. Linking: Combines object files with libraries to create executable (.exe).
6. Loading: Loads executable into memory.
7. Execution: CPU runs the program.
9 Write a program to count even and odd numbers in a 1D array. 
#include <stdio.h>
int main() {
    int n, arr[100], even=0, odd=0, i;
    scanf("%d", &n);
    for(i=0;i<n;i++) {
        scanf("%d", &arr[i]);
        if(arr[i] % 2 == 0) even++;
        else odd++;
    }
    printf("Even = %d, Odd = %d", even, odd);
    return 0;
}
